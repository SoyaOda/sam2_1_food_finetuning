# Emergency Memory Optimization Query

## 現状の問題
- 既存のメモリ最適化設定（解像度512、max_objects:5）を適用しても99.5%メモリ使用率でクリティカル
- CPUメモリが主な問題（GPUメモリは17-18%で安定）
- auto-resume機能との整合性を保ちつつ、さらなる最適化が必要

## 必要な技術調査
1. SAM2.1公式実装での最小動作要件とメモリ使用パターン
2. PyTorch/CUDA memory管理のベストプラクティス（特にCPUメモリ対策）
3. 学習データローダーのメモリ効率化手法
4. 動的バッチサイズ調整とcheckpoint resumeの実装方法
5. SAM2.1での最小解像度・オブジェクト数での学習効果

## Query Prompt作成用
auto-resume機能を保持しながら、CPUメモリ使用量を大幅に削減するSAM2.1学習の最適化手法について、公式実装を参考にした解決策を教えてください。これらについて、Qwen2.5-VL、SAM2.1、LISA等の公式実装を参考にした解決策を教えてください。
