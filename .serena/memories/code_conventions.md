# コード規約とスタイル

## Python コーディング規約
- Python 3.10+ の機能を使用
- 型ヒントは必要に応じて使用
- docstringは重要な関数に付与

## ファイル命名規則
- スクリプト: 番号プレフィックス付き（00_setup_env.sh, 10_prepare_foodseg103.py）
- 設定ファイル: Hydra YAML形式
- データ: SA-1B形式に準拠

## エラーハンドリング
- ダミーコードやフォールバックは避ける
- 適切にエラーを出力して処理を停止
- デバッグに有用な情報を提供

## 実装方針
- 公式実装（Qwen, SAM, Huggingface, PyTorch）を参考にする
- 予想や自前実装を最小限にする
- 不確実な部分はo3-queryで調査

## ディレクトリ構造
- external/: 外部リポジトリ
- data/: データセット
- scripts/: 処理スクリプト
- configs/: 設定ファイル
